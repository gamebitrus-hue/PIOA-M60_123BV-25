## Структура проекта

### main.py

Точка входа. Запускает текстовый интерфейс программы.

### tui.py

Модуль с текстовым интерфейсом пользователя.

- вывод меню
- вывод результатов на экран

## Функциональность

### Добавление сотрудника

Позволяет добавить нового сотрудника с указанием:

- Уникального ID
- Имени
- Должности
- Зарплаты (целое число)
- Отдела

### Поиск сотрудников

Гибкий поиск по следующим критериям:

- ID сотрудника (точное совпадение)
- Имя (точное совпадение)
- Должность (точное совпадение)
- Зарплата (точное совпадение)
- Отдел (точное совпадение)

Все фильтры опциональны — можно указать любую комбинацию.

### Просмотр всех сотрудников

Выводит полный список всех сотрудников в табличном виде.
