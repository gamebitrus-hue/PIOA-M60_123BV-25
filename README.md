## Структура проекта

```
employees_db/
├── backend/
│   ├── __init__.py
│   └── memory.py     
├── __init__.py
├── tui.py              
├── __main__.py     
└── README.md
```

### Назначение модулей

- **`backend/memory.py`** — реализует хранилище в виде списка кортежей и
  функции `create_employee`, `select_employees`. Здесь же выполняется
  валидация входных данных.
- **`tui.py`** — текстовый интерфейс: меню, ввод значений, вывод результатов,
  обработка ошибок пользовательского ввода.
- **`__main__.py`** — запускает главное меню (`run`).

## Функциональность

- **Добавление записей** с валидацией (уникальный ID, непустые поля,
  неотрицательные числовые значения).
- **Поиск записей с фильтрацией** по любому набору полей: ID, имени,
  должности, зарплате, отделу. Пустые фильтры игнорируются.
- **Просмотр всех записей**.
- **Обработка ошибок** ввода (некорректные числа, пустые обязательные
  поля, дублирующиеся ID) — пользователь получает понятное сообщение и
  возвращается в меню.
